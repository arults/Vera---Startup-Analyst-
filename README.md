# Vera — Startup Analyst

Vera is a probabilistic startup-investment research system. It treats startup outcomes as evidence-backed distributions, preserves provenance, and promotes empirical priors only after verification.

Current work: **Phase 1B — empirical reference-class calibration**, starting with the 2020 Wefunder Reg-CF cohort. The Phase-1 research architecture evolved through v0.2.10; the current Phase-1B engine lineage begins at v0.3.5. See `VERSION_PROGRESS.txt`, `docs/ITERATION_LOG.md`, and `checkpoints/` for the auditable history.
