# Vera — Startup Analyst

Vera is a probabilistic startup-investment research system. It treats startup outcomes as evidence-backed distributions, preserves provenance, and promotes empirical priors only after verification.

**Current version: v0.5.0. Phase 1C framework complete.** Vera retains the promoted Phase 1B Wefunder 2020 reference class and now includes an executable, censoring-aware multi-platform calibration framework for Wefunder, StartEngine, Crowdcube, Republic US and Republic Europe (2020–2025). Phase 1C does not contain the full multi-platform dataset or final rates.

See `docs/PHASE_1C_SPEC.md`, `decisions/PHASE_1C_DECISIONS.json`, `checkpoints/`, `VERSION_PROGRESS.txt`, and `docs/ITERATION_LOG.md`.
