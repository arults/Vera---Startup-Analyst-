# Vera — Startup Analyst

Vera is a probabilistic startup-investment research system. It treats startup outcomes as evidence-backed distributions, preserves provenance, and promotes empirical priors only after independent verification.

**Current version: v0.4.0. Phase 1B complete.** Vera's first promoted empirical reference class is the provenance-bound 2020 Wefunder five-year operating-survival cohort. See `reference_classes/`, `VERSION_PROGRESS.txt`, `docs/ITERATION_LOG.md`, and `checkpoints/` for the auditable evidence and evolution.
