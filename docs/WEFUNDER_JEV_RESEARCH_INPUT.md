# Vera Research Input — Wefunder/JEV Diligence Learnings

Date: 2026-10-08
Status: RESEARCH INPUT ONLY — not an empirical prior and not a promoted calibrated model.

## Purpose
This file preserves lessons from repeated live startup diligence so Vera can consult them alongside web research, SEC filings, founder answers, government/regulatory records, and future empirical reference classes. These learnings are hypotheses, heuristics, and model-design evidence; they must remain provenance-tagged and may not override verified source evidence.

## Core lessons
1. Separate company quality from investment attractiveness at the offered security/valuation.
2. User-facing outputs such as P(Buy), P(10x), P(25x), P(50x), P(100x), PWMOIC and IRR are decision-useful, but raw LLM/Jev outputs are judgment inputs rather than calibrated probabilities.
3. Nested return probabilities must come from one coherent return distribution so P10 >= P25 >= P50 >= P100.
4. Category rubrics such as team, product/science, market, traction, moat, financial health and valuation should be causal/explanatory features, not simply averaged into a final score.
5. Security terms and dilution materially change investor outcomes: SAFE cap/discount, pre/post-money basis, preferred/common, SPV, uncapped structures, liquidation preferences and future capital needs must be normalized before MOIC.
6. Evidence classes must be economically distinct: commercial revenue != grant income; firm contract != proposed vendor/LOI; preorder != recognized revenue; issuer claim != independent verification.
7. Every material claim should carry source/provenance, date, verification state, contradiction state and evidentiary weight.
8. Value-of-Information should identify the single milestone or unknown most likely to change the decision.
9. A good company can still be a poor investment at a high price; valuation affects investor return far more directly than operating survival.
10. Capital-intensive businesses require explicit financing-path simulation because follow-on dilution can erase apparent company-value upside.
11. Raw JEV probabilities should never be promoted as empirical truth; JEV is best used as an adjudicator/critic/promotion gate.
12. The final probability engine should start from empirical reference classes, test exchangeability, update with verified company evidence, model financing/security economics, and then generate a coherent post-dilution return distribution.
13. Until calibration is demonstrated on resolved forecasts, Vera should prefer uncertainty bands / UNCALIBRATED labels to false precision.
14. Forecast snapshots should later be scored against realized outcomes using Brier score, log score and reliability/calibration analysis.
15. Time matters: Vera should eventually model time-to-liquidity/IRR alongside MOIC.

## Market-sizing lesson
TAM/SAM/SOM should be supplemented by REM = Realistically Extractable Market:
REM = Reachable Customers × Penetration × ARPU × Retention.
REM should account for geography, distribution, sales capacity, pricing, adoption friction, competition and regulation. It is a scenario input to realistic revenue/exit modeling, not a standalone valuation shortcut.
